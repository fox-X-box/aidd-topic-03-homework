| Зависимости | Django 4.1.7, Celery 5.2.7, psycopg2; недоступные пакеты tinkoff | Django 5.2 LTS, Celery 5.6, psycopg 3; точный requirements.txt с прямыми зависимостями в requirements.in. Старые dev-only зависимости удалены из runtime. Установка проверена дважды |

## Сохранённые решения и ограничения

Общий каталог может изменять любой вошедший пользователь — это соответствует исходному HTML-сценарию. Администраторский-only каталог не вводился. Равная цена по-прежнему трактуется как «не падает». Уникальны FIGI, ticker и UID. API фильтры и поиск сохранены; default ordering стабилизирован.

Новая история требует защиты согласованности: валюту акции с сохранёнными ценами/операциями нельзя изменить, используемую акцию нельзя удалить. Эти ограничения вводятся вместе с новыми моделями и проверены отдельно. Старые UID-миграции не переписывались: свежая БД мигрируется, но для переноса уже заполненной БД старой версии до 0003 необходим самостоятельный план восстановления UID; реальной старой БД в этом сеансе не было.

Тесты исходных CRUD-сценариев сохранены; их клиент теперь аутентифицирован, а PUT включает обязательный UID. Это явное изменение политики безопасности и исправление дефекта контракта, а не отключение неудачных проверок. Добавлены отдельные тесты запрета анонимной записи и потери UID.

Проверки production deployment, ограничений бесплатных тарифов агентов и обращения к реальному брокеру не выполнялись. Ни один внешний сбой не обходился отключением TLS или вымышленным пакетом.
